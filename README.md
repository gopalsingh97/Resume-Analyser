# Resume Analyser

A mini project that analyses resumes and helps match them against job listings.

## Features

- Upload/parse resume content
- Analyse resume data against a jobs dataset
- Simple web interface (HTML, CSS, JS) connected to a Python backend

## Tech Stack

- **Backend:** Python (`app.py`)
- **Frontend:** HTML, CSS, JavaScript (`index.html`, `style.css`, `main.js`)
- **Data:** `jobs_dataset.csv`

## Getting Started

1. Clone the repository
```bash
   git clone https://github.com/gopalsingh97/resume-analyser.git
   cd resume-analyser
```

2. Install dependencies
```bash
   pip install -r requirements.txt
```

3. Run the app
```bash
   python app.py
```
